# Death's Decree

一个 Godot 4 原型：玩家扮演死神，通过左右滑动卡片决定处死哪一类人，并让秩序、恐惧、怜悯、冥币四个状态随剧情变化。

## 运行

双击 `Play_Game.bat` 可以直接游玩。有 Godot 时会打开 Godot 项目；没有 Godot 时会自动打开浏览器试玩版。

如果想放到桌面，双击 `Create_Desktop_Shortcut.bat`，它会创建一个桌面快捷方式，并绑定 `Ctrl + Alt + D`。

也可以用 Godot 4.x 打开这个文件夹，然后运行主场景 `res://scenes/main.tscn`。

## 当前内容

- 死神主题主界面和手绘风死神头像。
- 全屏背景会按审判地点切换，卡片里的角色单独显示并占更大面积。
- 四维状态已改为 QI/SP/FN/RB 四个纯 icon，icon 内部用竖向填充显示 0-100 分数。
- 10 张基础审判卡，以及循环后的后期事件卡。
- 四项状态数值和多个失衡结局。
- 鼠标与触屏拖拽支持。
- 浏览器试玩版在没有 Godot 时会自动打开。
- 卡片选项默认隐藏，只在玩家向左或向右拖动时按方向出现。
